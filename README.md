# 🎯 AI Recommendation System

A simple recommendation system built with Python and Gradio.

## Features

- Select multiple interests
- Add a custom interest
- Get personalized recommendations
- Match score for each recommendation
- Ratings and categories
- Clean and responsive Gradio interface

## Technologies

- Python
- Gradio

## How It Works

The application compares the user's selected interests with
the categories of available content.

Items with matching categories receive a recommendation score
based on the number of matches and the item's rating.
