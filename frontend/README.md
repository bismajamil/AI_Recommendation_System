# 🎯 AI Recommendation System

A content-based recommendation system that suggests personalized items 
based on user preferences and interests.

## Features

✅ Predefined interest categories (Python, Movies, AI, Data Science, Programming)  
✅ Custom interest input functionality  
✅ Content-based filtering algorithm  
✅ Real-time recommendations with matching scores  
✅ Beautiful responsive UI with Tailwind CSS  
✅ REST API backend with Express.js  

## Tech Stack

**Backend:**
- Node.js
- Express.js
- REST API

**Frontend:**
- React
- Tailwind CSS
- Axios

## How to Run

### Backend
```bash
cd backend
npm install
npm run dev
```
Server runs on `http://localhost:5000`

### Frontend
```bash
cd frontend
npm install
npm run dev
```
App runs on `http://localhost:5173`
